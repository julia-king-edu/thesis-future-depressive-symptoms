# Population-Level Screening for Future Elevated Depressive Symptoms: A Longitudinal Prediction Study
## Implementation Details

Steps to replicate the pipeline:
1. Clone the repository (the correct folder structure will be established through .gitkeep files)
2. Load the _thesis_future-depressive-symptoms.Rproj_ file & start renv if it does not boot automatically.
3. Paste the English R version of the SOEP-Core v41 dataset into the folder "_data/raw/soep-core.41_r_en_"
4. Run the files in "_analysis_" in order.

## Output

- "_data_" contains datasets reflecting all stages of the pipeline.
- "_models_" contains all workflows and workflow-sets produced during the pipeline.
- "_out_" contains all figures and latex exports of all tables generated throughout the pipeline.

## Note

Due to SOEP data protection, the raw dataset cannot be supplied here.
